Utilise le skill `ask-matt` pour déterminer quel skill ou flux de travail correspond le mieux à ta situation.

Ce skill agit comme un routeur qui te redirige vers le bon outil parmi l'ensemble des skills disponibles.

Utilise cette commande quand :
- Tu ne sais pas quel skill utiliser
- Tu as une question sur les capacités disponibles
- Tu veux explorer les options avant de commencer
