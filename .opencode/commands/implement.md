Utilise le skill `implement` pour exécuter un travail basé sur une spec ou un ensemble de tickets.

Ce skill :
- Prend une spec détaillée ou des tickets comme entrée
- Planifie et exécute l'implémentation
- Gère les tâches multiples en parallèle quand possible

Utilise cette commande quand :
- Tu as une spec claire à implémenter
- Tu as des tickets bien définis à exécuter
- Tu veux déléguer l'implémentation complète

Arguments : $1 (la spec ou les tickets à implémenter)
