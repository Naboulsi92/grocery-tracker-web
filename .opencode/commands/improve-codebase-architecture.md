Utilise le skill `improve-codebase-architecture` pour scanner le codebase et identifier les opportunités d'amélioration architecturale.

Ce skill :
- Analyse le codebase pour trouver des "deepening opportunities"
- Génère un rapport HTML visuel des améliorations possibles
- Te guide à travers le choix le plus impactant
- Te grille sur la direction à prendre

Utilise cette commande quand :
- Tu veux améliorer l'architecture du codebase
- Tu cherches à rendre le code plus maintenable
- Tu veux une vue d'ensemble des dettes techniques

Arguments : $1 (module ou zone spécifique à analyser, optionnel)
