Utilise le skill `research` pour investiguer une question contre des sources de confiance et capturer les findings.

Ce skill :
- Recherche dans les sources primaires de confiance
- Capture les résultats dans un fichier Markdown dans le repo
- Utilise Context7 pour la documentation à jour des bibliothèques
- S'adapte aux besoins spécifiques (API, best practices, etc.)

Utilise cette commande quand :
- Tu veux comprendre une bibliothèque/framework
- Tu as besoin de documentation précise et à jour
- Tu veux investiguer un sujet technique

Arguments : $1 (la question ou le sujet à investiguer), $2 (format de sortie souhaité)
