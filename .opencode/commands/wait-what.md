description: Arrête - le dernier message n'est pas passé, reformule
agent: general
---

Utilise le skill `wait-what` quand le dernier message n'est pas clair ou n'est pas passé.

Ce skill :
- Re-pitch le dernier message de manière plus claire
- Identifie ce qui n'a pas été compris
- Reformule la question ou l'instruction

Utilise cette commande quand :
- Tu n'as pas compris la dernière réponse
- Tu veux que l'agent reformule
- Tu veux clarifier une instruction ambiguë

Arguments : $1 (ce qui n'est pas clair, optionnel)
